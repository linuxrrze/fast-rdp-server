fast-rdp-server APT repository

Setup: see docs/packaging.md in the source repository.

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/fast-rdp-server.asc https://linuxrrze.github.io/fast-rdp-server/fast-rdp-server-archive-keyring.asc
# /etc/apt/sources.list.d/fast-rdp-server.sources
Types: deb
URIs: https://linuxrrze.github.io/fast-rdp-server
Suites: <codename>-stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/fast-rdp-server.asc

Suites

  • resolute-stable: fast-rdp-server for Ubuntu 26.04 (resolute), stable channel (release tags)
  • resolute-testing: fast-rdp-server for Ubuntu 26.04 (resolute), testing channel (main branch)
  • trixie-stable: fast-rdp-server for Debian 13 (trixie), stable channel (release tags)
  • trixie-testing: fast-rdp-server for Debian 13 (trixie), testing channel (main branch)
